# Contributing to Telegram AI IT Automation Agent

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## 📝 How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/your-username/telegram-ai-it-automation-agent.git`
3. **Create a branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`
4. **Make your changes** and ensure everything runs perfectly in your local environment.
5. **Run tests** using `pytest tests/` to verify your changes haven't broken any existing functionality.
6. **Commit your changes**: `git commit -m "feat: describe your feature here"`
7. **Push to your fork**: `git push origin feature/your-feature-name`
8. **Open a Pull Request (PR)** against the `main` branch.

## 🛠️ Code Style & Guidelines

- We follow **PEP 8** style guidelines for Python.
- Always include **docstrings** for new classes and functions.
- Update the `tests/` directory if you introduce a new feature.
- Ensure the **Safety Engine** (`src/safety.py`) is never bypassed. Security is our top priority.

## 🐛 Reporting Bugs

If you find a bug, please create an issue using the Bug Report template. Provide as much detail as possible, including:
- Steps to reproduce
- Expected vs actual behavior
- OS, Python version, and Logs

## 💡 Proposing Features

Feature requests are welcome! Use the Feature Request template to pitch your idea before writing code, so we can ensure it aligns with the project's roadmap.

Happy coding! 🚀
